# Тестовый проект для первой проверки runner

Минимальный React + TypeScript + Vite проект: без секретов, без базы, без переменных окружения.

Ожидаемый результат сборки: папка `dist` с двумя файлами (`index.html` и один `.js` в `assets`), около 150 КБ.

Команды, которые выполнит runner: `npm ci --ignore-scripts --no-audit`, затем `npm run build`.

Использование: создайте на GitHub отдельный публичный репозиторий (например `studio-runner-sample`) и загрузите в него содержимое этой папки (включая `package-lock.json`). Публичный репозиторий не требует токена. Сам репозиторий должен быть именно вашим: не подключайте чужие.
